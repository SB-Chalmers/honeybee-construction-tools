# Migration and provenance

This project was extracted from [SB-Chalmers/ComputationSustainableDesign](https://github.com/SB-Chalmers/ComputationSustainableDesign) at commit [`7f61d112e0d60667bbef3e6fc4fc7236bcf6bbba`](https://github.com/SB-Chalmers/ComputationSustainableDesign/commit/7f61d112e0d60667bbef3e6fc4fc7236bcf6bbba) on 2026-10-22.

Relevant Git history and original contributor attribution have been retained. The extraction reorganizes documentation and separates archived data from working code; it does not change the scientific methods or claim that legacy workflows have been validated.

The machine-readable [migration manifest](../migration.json) records every original file, its destination or archive status, its original download link, size, and SHA-256 checksum. Generated outputs and backups remain recoverable from the original commit. Large inputs use immutable links to the original repository until a project member supplies a dedicated archive DOI.

The research project template guides the overview, reproduction documentation, data inventory, citation metadata, and assistant instructions. MIT licensing was explicitly requested for this migration. Third-party software and input data retain their original notices and terms.
